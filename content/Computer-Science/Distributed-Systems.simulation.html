All 5 nodes are up and the network is whole. Write from either side — it reaches a quorum and the store stays consistent.

Model: a write from the client's side reaches every live node on that side and commits if at least 3 nodes (a majority of all 5) acknowledge. Consistency holds only while every live node stores the same value. This is a simplified stand-in for real consensus (Raft, Paxos), which also elects a leader and replicates a log.
