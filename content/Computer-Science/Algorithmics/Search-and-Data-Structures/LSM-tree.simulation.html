LSM-Tree

Flush and compaction happen automatically, LevelDB-style: the memtable flushes to L0 as one SST when full (5 keys = 2 MB); when L0 exceeds its cap (10 MB = 5 SSTs), only ONE L0 SST is compacted into L1 (merged with the overlapping L1 SSTs), so each compaction stays small. Higher levels have 10× caps.
